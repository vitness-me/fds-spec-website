# ¿Qué se puede hacer con FDS?

El Fitness Data Standard es un vocabulario compartido para datos de fitness — desde un
solo ejercicio hasta un plan de doce semanas. Esta sección responde una sola pregunta:
**¿qué se puede hacer realmente con él?**

Las capacidades se construyen unas sobre otras. La **biblioteca compartida** es el
vocabulario en el que está escrito todo lo demás. Las primitivas de **prescripción**
expresan la intención — cuánta carga, cuántas repeticiones, cuánto descanso — como
piezas reutilizables. La **composición** las une en sesiones y planes. Pueden leerse
en ese orden, o saltar directamente a la que corresponda al problema que se tenga
delante.

Cada ejemplo de cada una de las páginas siguientes se carga directamente desde un
archivo publicado del estándar. Nada aquí es meramente ilustrativo, y nada está
escrito a mano: si un archivo cambia de nombre o una versión se incrementa, la
compilación falla antes de que la página pueda quedar obsoleta.

## Lo que FDS deliberadamente no hace

FDS no modela a ninguna persona. No hay identidad del atleta, ni peso corporal, ni
repetición máxima (1RM), ni ningún resultado ejecutado o registrado en ninguna parte
del estándar. Es una decisión de diseño, no una carencia: un documento que no describe
a nadie puede publicarse, almacenarse en caché, replicarse y diferenciarse libremente,
sin obligación alguna de consentimiento, retención o borrado. Cada prescripción
anterior referencia los números personales que necesita en lugar de llevarlos
consigo — véanse las [Primitivas de prescripción](/docs/use-cases/prescription) para
saber cómo, y la [hoja de ruta](/docs/governance/roadmap) para ver dónde los datos
ejecutados quedan deliberadamente fuera del alcance.
