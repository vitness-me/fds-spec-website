# Glosario — español (`es`)

Un término por concepto, usado en todo el sitio. Registro: español neutro
internacional, formas impersonales o de usted, nunca `vosotros`. Los nombres
de entidades, campos de esquema, comandos e identificadores no se traducen.
En las cadenas de la interfaz se usan comillas inglesas ("…"); las angulares
(«…») quedan para las notas de este glosario.
